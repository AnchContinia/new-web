What never happens

Four things you will not be doing.

  • Signing into a second system.Continia opens where Business Central opens — same sign-in, same session, same user.
  • Exporting a file so another system can read it.The data is already in the tables the rest of your finance work uses.
  • Reconciling two sets of records.There is one record. Continia reads from it and writes to it.
  • Running an integration project.Installation is an extension from Microsoft AppSource, set up with your partner.
